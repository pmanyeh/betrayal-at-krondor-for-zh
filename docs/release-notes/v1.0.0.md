# Betrayal at Krondor 繁體中文版 v1.0.0

《*Betrayal at Krondor*》（1993 年 Dynamix / Sierra 發行的 DOS 經典 RPG）繁體中文化計畫，第一個正式發布版本。

本專案不是「破解字型顯示」或手刻二進位補丁，而是拿 [`canassa/betrayal-at-krondor`](https://github.com/canassa/betrayal-at-krondor) 逆向工程還原出的完整 C 原始碼，直接在原始碼層級加入中文渲染與新功能，再用真正的 1993 年 Borland C++ 3.1 工具鏈重新編譯——每次修改都跟原版二進位做雜湊比對，確保沒改到的部分逐位元組相同。所有改動都是可讀、可審查、可重新編譯驗證的原始碼，細節請見 [README](../../README.md)。

## 版本基礎

本版以《Betrayal at Krondor》**v1.00 Floppy 版**為安裝基礎，並回植官方 v1.02 中不依賴光碟資料的程式修補：

- 存檔寫入範圍與舊存檔相容性保護
- 角色狀態、屬性計算與遊戲平衡調整
- 戰鬥角色、敵方 AI、行動判定、法術與戰鬥統計修正
- 世界物件、接近偵測、場景事件與對話流程修正
- 近距離地圖可按 N 切換固定北方朝上／隨隊伍旋轉

上述回植已用 v1.00 遊戲資料驗證過地圖、戰鬥、章節切換、存檔寫入及既有舊存檔讀取，**未混入任何需要 v1.02 CD 資源的功能**——本版仍是磁片版架構，不支援 MSCDEX、CD 音軌或光碟版專用資源，也不能用 v1.02 CD 版 `KRONDOR.EXE` 直接安裝。

## 中文化內容

- 完整翻譯十章主要對話、章節書籍、物品、法術、怪物、地名、人物名與玩家常用選單。
- 新增 16×16 中文主字型、10×10 緊湊介面字型，支援中英數字混排。
- 針對對話框、法術說明、戰鬥面板、角色狀態、物品資訊、神殿治療與傳送畫面調整中文字級、換行、裁切與欄位位置。
- 六名固定隊員姓名會在**新遊戲範本**中轉為中文；安裝程式不會修改玩家既有存檔。

## 新增功能

### 訊息紀錄
3D 探索時按 `L`，或開啟選項並選擇「訊息紀錄」，可回看已顯示的對話、玩家回答與劇情。同一段對話中同一人物被分頁顯示的連續文字會合為一筆；清單顯示時間、人物／地點與本文摘要，內容頁保留當時文字與秒級時間。交易、系統、戰鬥、法術與謎題訊息不收錄。

每份存檔的同名 `.MLG` 保存當時完整歷史；存檔時只寫入自上次存檔後新增的紀錄，長時間遊玩後存檔速度不會愈來愈慢。讀取較早存檔，紀錄也回到當時，之後的遊玩形成新分支。備份或搬移存檔時請把 `.GAM` 與 `.MLG` 一起複製；舊存檔沒有 `.MLG` 時仍可遊玩，只是無法補回過去對話。

### 現代化探索操作
- 3D 探索與近距離地圖支援 `W`／`S` 前後、`A`／`D` 轉向、`Q`／`E` 左右平移。
- 按 `F2` 切換滑鼠視角模式（預設關閉）：開啟後以滑鼠轉向，準星指到可互動物件時按 `E` 或滑鼠左鍵互動，按住 `Ctrl` 可暫時恢復游標操作畫面按鈕。保留原版 3D 景窗、邊框、隊員肖像、按鈕、狀態文字與羅盤，不會放大至全螢幕。
- 3D 探索及城鎮／室內場景按住 `Tab`，可框出目前有效的可互動人物與物件。

### 自動存檔與快速存讀檔
- 自動於新章節開始、載入新探索區域、離開城鎮／室內、戰鬥結束，以及紮營或付費休息推進時間後存檔，固定輪替 `GAMES\AutoSave.G99` 內最多 10 筆。
- 3D 探索時按 `F5` 快速存檔、`F9` 讀取最新有效快存，位於 `GAMES\QSave.G98`，最多保留 20 筆，`F9` 會自動跳過損毀或版本不符的檔案。
- 寫入一律使用暫存檔、格式驗證與舊檔備份替換降低壞檔風險，存檔當下會顯示「正在存檔…」提示。AutoSave／QSave 可從讀檔畫面開啟，但不會成為手動存檔或書籤目的地。

### 地圖功能強化
- 近距離地圖左上新增可點擊的旋轉指北針（白色隨隊伍旋轉、紅色北方鎖定），也可按 `N` 切換。
- 玩家看見已登錄的洞穴、礦坑或地城入口後，近距離地圖會持久顯示範圍菱形；伊夏之眼、The Unseen、Nacre Cicatrix 三種察覺法術曾顯示的目標，也會以紅點保留並隨存檔保存。
- 完整世界地圖的城鎮名稱已中文化，並修正切換地名時的殘影。

### 角色與法術介面強化
- 角色法術頁改為互動式瀏覽器：可切換六個學派、查看已學法術清單與完整中文說明，學派圖示顯示已學數量。
- 3D 探索畫面上方的常駐效果圖示可直接點擊，查看法術作用與剩餘遊戲內時間；資訊卡不暫停操作，三秒後自動消失。
- 紮營畫面的圖片式英文按鈕改為「休息至康復／取消／離開」中文按鈕。

### 場景與便利功能
- 城鎮、旅店、商店、神殿等場景的長篇中文說明可逐頁閱讀，並有明確的「離開」操作，不會因文字變長而遺失內容。
- 修正第二章羅姆尼「黑羊酒館」互動熱區消失、無法推進主線的問題。
- 改善中文模式下的記憶體配置與多處繪圖／字庫問題，降低進出大型場景時的記憶體不足及畫面異常。

完整按鍵對照請見整合包內的「中文按鍵說明.txt」。

## 密技功能（進階密技中心）

這是一個**選用、非一般遊玩必要**的除錯／測試功能，預設不會出現在正常流程中，啟用狀態只維持到本次遊戲結束，不會修改任何設定檔或存檔預設行為。

**啟用方式：**
1. 在遊戲中打開任一寶箱選單，選擇「啟動進階密技中心」。
2. 回到 3D 探索畫面後，按住右 `Shift`＋`Alt`，再按反引號鍵（`` ` ``）開啟密技選單。

**可用功能：**
- 取得金幣／物品
- 調整角色能力
- 直接前往下一章
- 治療全隊
- 學會全部法術
- 開放「傳送地點」——啟用後可在完整世界地圖上左鍵點擊 33 個有名稱的地點，直接傳送至附近的固定位置，方便測試劇情與地圖。這 33 個落點均已逐一實機驗證；抵達後會排程一次自動存檔，但**不會**推進遊戲時間或主動改變任務狀態。

一般遊玩模式下不會啟用此功能，地圖上其他無名位置也無法傳送；若不主動從寶箱選單開啟，遊戲行為與沒有此功能時完全一致。

## 如何取得與安裝

基於「不散布原版遊戲資產」原則，整合包**不包含**任何原版遊戲檔案，也不包含編譯好的 `KRONDOR.EXE`：

1. 解壓整合包。
2. 把自己合法取得的 v1.00 Floppy 版（1993-06-16）遊戲檔案放進 `game_data/` 資料夾。
3. 雙擊「安裝中文化.bat」——會先驗證雜湊值，版本不符會直接中止、不動任何檔案。
4. 雙擊「玩遊戲.bat」開始遊玩；整個資料夾可直接搬到別的地方。

整合包內附官方預先編譯的 DOSBox-X（GPLv2）與可嵌入版 Python（PSF 授權），不需要另外安裝。詳細說明見專案 [README](../../README.md)。

## 已知限制

- 目前只支援 v1.00 Floppy 版，尚未支援 v1.02 CD 版遊戲資料。
- 極少數對話框在分頁到最後一頁時，可能只剩一個標點符號單獨成頁，根因尚未解決。
- 部分章節書籍（BOK）的放大首字圖像仍是原版英文美術字，尚未重繪為中文版本。
- 少數已翻譯章節尚未經過第二人校對，如發現翻譯或排版問題歡迎回報。

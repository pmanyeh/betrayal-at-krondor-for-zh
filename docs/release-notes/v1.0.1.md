# Betrayal at Krondor 繁體中文版 v1.0.1

v1.0.0 之後的第一個更新版本：新增 Mac 支援，並修正自動存檔提示的顯示問題。翻譯內容與其他功能和 v1.0.0 相同，完整功能說明請見 [v1.0.0 發布說明](v1.0.0.md)。

## 新增：Mac 支援

整合包新增 Mac 啟動腳本 `play_mac.sh`，**PC 與 Mac 共用同一個 zip**。

Mac 玩家需要自備：
- **Python 3**：在「終端機」輸入 `python3 --version` 確認。較新的 macOS 第一次執行時若提示安裝「命令列開發者工具」，依指示安裝即可。
- **Mac 版 DOSBox-X**（<https://dosbox-x.com/>）：把 `dosbox-x.app` 放進 `/Applications`、`/Applications/Games`，或直接放進整合包資料夾。

安裝與遊玩：

1. 解壓整合包，把遊戲檔案放進 `game_data/`。
2. 在終端機切換到整合包資料夾，執行 `python3 installer.py`。
3. 執行 `./play_mac.sh` 開始遊玩。

若 macOS 阻擋開啟 `dosbox-x.app`，請到「系統設定」→「隱私權與安全性」點「仍要開啟」，或執行 `xattr -cr /路徑/到/dosbox-x.app`。Mac 鍵盤的 F 鍵若預設是媒體鍵，請搭配 `fn`（例如 `fn` + `F5` 快速存檔）。整合包內的 `README_安裝說明.txt` 有完整的 Mac 說明。

Mac 啟動方式參考玩家 [@wesley316-Guybrush](https://github.com/wesley316-Guybrush) 在 [#1](https://github.com/pmanyeh/betrayal-at-krondor-for-zh/issues/1) 提供的腳本與說明，並由其在 Mac 上實機測試確認，特此感謝。

## 修正

- 開新遊戲或進入新章節時，自動存檔的「正在存檔…」提示不再閃爍。
- 自動存檔完成後，「正在存檔…」提示會立即消失，不必等玩家操作才重繪。

## 如何取得與安裝

整合包同樣**不包含**任何原版遊戲檔案，只支援 v1.00 Floppy 版（1993-06-16）。

- **Windows**：解壓 → 遊戲檔案放進 `game_data/` → 雙擊「安裝中文化.bat」→ 雙擊「玩遊戲.bat」。
- **Mac**：見上方「新增：Mac 支援」。

**從 v1.0.0 升級**：v1.0.1 的中文化 `KRONDOR.EXE` 與 v1.0.0 不同。請先在舊整合包中解除安裝（Windows：`python-embed\python.exe installer.py --uninstall`），再把 `game_data/` 的遊戲檔案搬到新整合包中重新安裝。存檔（`.GAM` 與 `.MLG`）可繼續使用，搬移時請一起複製。

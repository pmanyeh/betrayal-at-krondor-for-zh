# 訊息紀錄：AI agent 施工與驗收清單

日期：2026-09-06。配套規格：[message-log-design.md](message-log-design.md)。本文件是未執行的工程清單，所有 checkbox 初始未勾。

## 使用方式

建議每次交給 agent 一個階段，完成後先看交付報告再進下一階段。不要一次要求能力較弱的 agent 同時修改對話 VM、存檔交易和 UI。各階段仍屬同一功能，第一版須完成第 0–7 階段；第 8 階段是選配。

可直接複製這段派工文字，替換 N：

> 請先閱讀 docs/research/message-log-design.md 與 docs/research/message-log-agent-tasks.md，執行第 N 階段。先查看目前 Git 狀態、適用的 AGENTS.md、HANDOFF.md 及上階段結果。沿用目前繁中 DOS 引擎與資源管線，不改 GAM 格式，不把規劃假設當已驗證事實。只在本階段範圍內修改；完成必要編譯／驗證。將結果寫入 docs/research/message-log-progress.md，列出修改檔案、實際命令與結果、未解事項、下一階段起點。尚未做的實機驗證明確標未驗證。不要向 upstream 遠端 push，不覆蓋其他人的 WIP，不自動更新正式發布包。

閱讀文件後，已確定的需求不必反覆詢問。只有需要改變玩家需求／破壞相容性時才提出具體選擇；找不到工具鏈則記錄阻礙及已完成的靜態工作，不能把未編譯當成功。

## 第 1 階段：格式凍結與檔案核心

依賴：第 0 階段。先做與 UI／VM 分離的資料核心。

建議新檔位置（不是已存在檔案）：引擎 `bak/SRC/DIALOG/MSGLOG.C`／`.H`；主 repo `tools/text/message_log.py`、`tests/unit/test_message_log.py`；實際名稱配合既有建置規範。

- [ ] 寫出 MLG v1 的 byte offset／size／endianness／checksum 範圍／最大長度／字串編碼／事件 kind 表，附至少兩個可手算的 golden fixtures。可另建 `docs/research/message-log-format.md`。
- [ ] 定義工作檔與 snapshot 標頭差異、正常 close 與 append 中斷的已提交尾端判定，不要求每次追加都重算整個歷史 CRC。
- [ ] 定義純資料 API 的責任：new timeline、append visible span、append choice、begin/end conversation、prepare snapshot、load candidate、activate candidate、read page、shutdown。API 名稱可調整；失敗返回值必須可區分原因。
- [ ] 狀態至少区分 inactive、active、transition、viewer、recording-failed；viewer 只能抑制收錄，不能讓原先 failed 狀態在離開時誤變 active。
- [ ] 實作分塊讀寫、邊界檢查、CRC32、長度／offset 防溢位、雙字元安全分片；不直接序列化 C struct。
- [ ] 人物／地點／字串為當下快照，不保留暫存 pointer；編碼 mapping 指紋可由建置工具生成常數。
- [ ] Python decoder/validator 可輸出 UTF-8 診斷資料，使用相同 mapping；不把 Python 設為遊戲執行必要條件。
- [ ] 確認 16 位元 compiler/linker 接受新模組及型別，量測常駐記憶體增加量。

必要測試：空檔、正常多事件、未知版本、截斷標頭／事件、錯 CRC、非法長度、offset 越界、中文 trail 為 `#`／`@`、跨 64 KiB 總長度、超過單片上限、mapping 不匹配、損壞最後一筆的可驗證前綴。測試驗證檔案契約，不只 grep C 原始碼。

完成門檻：由 C 產生的 fixture 能被 Python 正確解讀；Python fixture 能由 DOS 核心讀取。只有 Python 模型互讀不算完成跨語言驗證。

## 第 8 階段：選配查詢功能

這不是第一版必要條件，不得為此延後核心時間線與收錄修正。

- 人物／地點篩選：由歷史名稱與穩定 ID 建立選項，未知人物不能全誤合併；以串流掃描或可重建索引實作。
- 全文搜尋：先確認 DOS 中文輸入可行性，可改為從已有話題選字／詞。若只支援英文、數字，需在規格中明示，不能稱作完整中文搜尋。
- UTF-8 匯出：可由離線 Python 工具完成；工具不得執行 DDX 腳本。
- 壓縮／共用歷史：只有實測容量或延遲值得才另寫 ADR；必須重新設計刪檔、搬移和版本遷移，不在本版偷偷引入。

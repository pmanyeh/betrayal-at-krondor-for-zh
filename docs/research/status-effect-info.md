# 常駐效果圖示資訊卡

## 功能

一般 3D 探索畫面上方會以特殊字型 glyph 顯示目前生效的隊伍／世界計時效果。
現在可直接用滑鼠左鍵點擊個別圖示，開啟兩行中文資訊卡：

1. 法術名稱與效果摘要。
2. 剩餘的遊戲內時間，依長度顯示日、時、分。

資訊卡會暫停世界操作；按 `Esc`、`Enter`、滑鼠左鍵或右鍵關閉。關閉後主選單、
常駐圖示與 3D 場景會完整重繪。滑鼠視角捕捉期間不接受圖示點擊；按住 `Ctrl`
恢復 UI 游標後即可操作。

## 資料與換算

- 圖示與效果 ID：`SPELLFX.C` 的 `g_event_caption_glyph_table[9]`。
- 啟用狀態：`g_gameState.wPalEventMask`。
- 剩餘時間：`g_gameState.aTimerEventPool` 中 `bKind == 2` 且 `wSub_id == effect_id`
  的 `nValue`。
- 遊戲時間換算：30 ticks 為 1 分鐘、1800 ticks 為 1 小時；顯示時向上取整，
  避免仍有效但不足一分鐘的效果顯示為 0 分。
- 重複施放會由原版 `timerpool_upsert(..., 0x80, value)` 累加時間，資訊卡直接顯示
  累加後的剩餘值。

目前原版程式真正建立計時器的六種 caption 效果為龍息術、燭光術、星暮術、
光影欺敵、通解術與薩瑞格之嗅。其餘三個保留槽若由特殊存檔啟用，會顯示通用名稱。

## 命中判定

Caption 會依當前有效圖示總寬度在 x=160 置中，因此不能使用固定矩形。命中函式
先用和繪圖函式相同的 glyph 順序重建整串、算出置中起點，再逐 glyph 使用實際字寬
累加命中範圍。效果數量改變後不需維護另一份座標表。

## 驗證

- Python 回歸測試：`tests/unit/test_status_effect_info.py`。
- Borland C++ 3.1／Turbo Link 5.1 完整 clean build 成功。
- `VMCODE.OVL`、`SX.OVL` 與基準版 byte-identical。
- 待 DOSBox-X 實機確認個別圖示命中、中文字形、倒數值與關閉後重繪。

## 實機驗收清單

1. 讓兩種以上效果同時生效，分別點每個圖示，確認名稱不會錯位。
2. 核對顯示時間與剛施法的理論持續時間；移動或休息後再次查看，確認時間下降。
3. 重複施放同一效果，確認顯示累加後的時間。
4. 分別以 `Esc`、`Enter`、左鍵與右鍵關閉，確認不會把關閉操作傳給場景。
5. 關閉後確認 3D 畫面、上方圖示、羅盤與按鈕沒有殘影。
6. 開啟 F2 滑鼠視角時圖示不應誤觸；按住 `Ctrl` 恢復游標後應可點擊。

# 自動存檔

## 玩家行為

- 自動存檔集中在 `GAMES\AutoSave.G99`，不存在時自動建立。
- 實體檔名固定使用原引擎可辨識的 `SAVE01.GAM`～`SAVE10.GAM`，最多保留十筆。
- 畫面名稱使用 DOS 系統日期與當日流水碼，例如 `20260902_1`、`20260902_2`。
- 同日流水碼不因十槽輪替而重設；超過十筆時覆蓋整體最舊紀錄。
- 讀檔畫面顯示 `AutoSave` 資料夾，內容以日期與流水碼由新到舊排列。
- 手動存檔／刪除畫面隱藏 `AutoSave`；從自動存檔載入後，書籤與章末標記也不能寫進該資料夾。
- 原版手動存檔資料夾實際可用 `SAVE01.GAM`～`SAVE20.GAM`；自動存檔只保留十筆是本專案的產品規則，不是引擎限制。

## 觸發點

下列事件只提出請求，實際寫入延後到 3D 世界完成重繪、且不在戰鬥退出或章節退出途中時執行：

1. 新章節初始化完成。
2. 傳送或載入新的探索區域。
3. 離開城鎮／室內場景並返回探索。
4. 戰鬥結束並返回探索（勝利或撤退，隊伍全滅不寫入）。
5. 紮營或付費休息確實推進遊戲時間後。

單純讀取既有存檔不會立即觸發，避免尚未進行任何遊戲操作就產生一筆重複紀錄。

## 寫入安全

1. 先把完整狀態寫入不會被讀檔介面列出的 `AUTONEW.GAM`。
2. 驗證 0x16 存檔版本、100-byte 標頭與完整檔案大小 334,605 bytes。
3. 替換既有槽位前先改名為對應的 `AUTOBnn.GAM`。
4. 新檔改名成功後才刪除備份；若中途失敗則還原舊槽位。
5. 下次服務自動清理殘留暫存檔，並復原缺少正式槽位的備份。

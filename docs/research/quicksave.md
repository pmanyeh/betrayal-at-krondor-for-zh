# 快速存檔／讀檔

## 玩家操作

- 正常 3D 探索時按 `F5`：建立一份快速存檔。
- 正常 3D 探索時按 `F9`：直接讀取最新且有效的快速存檔。
- 對話、戰鬥、城鎮／室內場景、選單及過場期間不攔截這兩個按鍵。

## 儲存配置

快速存檔與既有自動存檔完全分離：

```text
GAMES\QSave.G98\SAVE01.GAM
...
GAMES\QSave.G98\SAVE20.GAM
```

每筆標題沿用自動存檔已驗證的 `YYYYMMDD_sequence` 格式。未滿 20 槽時優先使用第一個空槽；全部已滿時，以標題日期及序號判定並覆寫最舊的一筆。檔名編號只代表實體槽位，不代表時間順序。

`QSave.G98` 可由一般「讀取進度」畫面選取，方便玩家手動回到較早的快速存檔；它刻意不出現在「儲存進度」畫面，也不能接收書籤，以免一般手動檔案破壞輪替資料的時間標題。

## 寫入安全

快速存檔沿用 `mainmenu_save_party_to_tmp()` 取得完整世界／角色／物品狀態，再採以下提交程序：

1. 寫入 `QSNEW.GAM`。
2. 驗證標頭與檔案大小符合正式存檔格式。
3. 將目標槽暫時更名為 `QSBnn.GAM`。
4. 將新檔更名為正式的 `SAVEnn.GAM`。
5. 成功後刪除備份；若更名失敗，恢復原目標檔。

每次使用前也會清理未完成的暫存檔，並恢復只剩備份、沒有正式檔案的中斷狀態。

## 載入安全

`F9` 會逐一驗證 20 個槽位，忽略截斷、版本不符或標題格式錯誤的檔案，選出日期／序號最新者。選定後只設定現有存檔槽全域值，並令 `world3d_main_loop()` 回傳既有的 mode 3；上層 `gmain_start_dispatch()` 會先走完整的場景卸載流程，之後才呼叫原本的 `savegame_read()`。這避免在活躍世界資源仍存在時直接替換遊戲狀態。

目前依需求採直接載入，不另外顯示確認視窗。找不到任何有效快速存檔時，沿用既有「此目錄沒有可讀取存檔」訊息，遊戲繼續留在目前場景。

### 實機驗收清單

- [ ] 按 `F5` 後建立 `QSave.G98` 與第一份快存。
- [ ] 移動或改變物品後按 `F9`，回到最近一次 `F5` 的狀態。
- [ ] 普通讀檔畫面可看見 QSave 及其中的快存。
- [ ] 普通存檔畫面不列出 QSave，書籤也不寫入 QSave。
- [ ] 建立超過 20 次後仍只有 20 份正式快存，且最舊一份被替換。
- [ ] 最新檔損毀或截斷時，`F9` 能退回下一份有效快存。
